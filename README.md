-->Property Analysis SQL Project

This project focuses on analyzing real estate property data using MySQL to uncover meaningful insights about pricing, trends, and property types.

----------

-->Overview

The analysis explores housing market data to identify patterns such as:

- Price distribution
- Popular property types
- Bedroom-based demand
- Year-wise sales trends

----------

-->Skills Used

- SQL for data analysis
- Data filtering and aggregation
- Window functions
- Data categorization using logic

----------

-->Files Included

- SQL queries performance video
- SQL queries file
- Project presentation

----------

-->Key Insights

- Identified high and low price segments
- Compared different property types
- Analyzed trends over time
- Found most common bedroom configurations
